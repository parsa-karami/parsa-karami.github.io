Speed Prediction from Acceleration

12% RMSE · 0–120 km/h
PythonXGBoostNeural NetsEmbedded

Overview

Calculating speed from acceleration data is difficult because of white noise, sensor biases, and sensor inaccuracies. I approached this problem with machine learning instead of direct integration.

Approach

To build the labelled dataset, I used a Neo-M8 GPS module to record speed and an ADXL345 accelerometer to record acceleration, then synchronized the two streams. I performed feature engineering on the acceleration signal to extract additional information.

I compared linear regression, decision trees, XGBoost, and neural networks for predicting speed from acceleration. The best result was a 12% RMSE over a 0–120 km/h range.

Stack

Python, XGBoost, neural networks, and embedded sensor data acquisition.
